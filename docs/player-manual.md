# 《我是区》玩家试玩操作手册

## 这是什么

《我是区》当前是一个 Godot 4.6 2D 动作游戏原型。

这份试玩版的目标不是完整通关，而是让你体验当前已经接入的几个核心动作：

- 移动
- 闪避
- 基础近战攻击
- 与训练目标 `ThreatDummy` 的交互

---

## 如何启动游戏

### 方式 1：在 Godot 编辑器中打开

直接用 Godot 打开项目根目录下的 `project.godot`，然后运行项目。

### 方式 2：命令行启动

如果本机已经放好了项目约定里的 Godot 可执行文件，可以使用：

```bash
"D:/environment/Godot_v4.6.2-stable_win64.exe/Godot_v4.6.2-stable_win64.exe" --path "D:/workspace/ai/mythboss"
```

## 操作说明

### 移动

- `W A S D`
- 或方向键 `↑ ↓ ← →`

角色会按照输入方向进行八方向移动。

### 闪避

- `Space`

角色会朝当前输入方向进行一次短距离闪避。

如果当前没有移动输入，则会朝角色当前朝向闪避。

### 攻击

- 轻攻：`J` 或 鼠标左键
- 重攻：`K` 或 鼠标右键

角色会朝当前输入方向，或当前朝向，打出一次短近战攻击。

攻击期间：

- 角色会短暂停下
- 不能立刻连续攻击
- 不能在攻击过程中插入闪避

在轻攻与重攻之间快速切换时，会获得一个很短的无敌窗口。

## 当前试玩内容

进入主场景后，你会看到：

- 一个可操作的玩家角色
- 一个训练目标 `ThreatDummy`
- 一个用于试玩的场地边界

`ThreatDummy` 会周期性地：

1. 进入预警状态
2. 发动范围攻击
3. 进入恢复状态
4. 重复循环

你可以围绕它进行以下试玩：

- 练习走位
- 在它攻击前用闪避躲开
- 靠近后用近战攻击命中它
- 观察命中后它的反馈和攻击节奏重置

---

## 试玩目标建议

如果你第一次试玩，可以按这个顺序体验：

### 1. 先熟悉移动

围着场地移动一圈，感受角色朝向变化。

### 2. 再练习闪避

等 `ThreatDummy` 进入预警后，尝试用 `Space` 躲开它的攻击范围。

### 3. 最后练习攻击

靠近 `ThreatDummy`，按 `J`（或鼠标左键）发动轻攻；按 `K`（或鼠标右键）发动重攻。

如果攻击距离和方向正确，你会看到：

- 攻击动作生效
- 训练目标出现受击反馈
- 它当前的攻击节奏被打断并重置

---

## 当前规则说明

- 玩家被 `ThreatDummy` 命中后，会回到出生点
- 闪避有效帧内可以规避威胁
- 攻击是短距离、定向的
- 攻击打空不会产生额外效果
- 当前版本还没有血量、连击、击杀、UI 提示等完整系统

---

## 如果你想重点测试

建议重点关注下面几项：

- 移动是否顺手
- 闪避方向是否符合预期
- 攻击方向是否直观
- 攻击距离是否容易理解
- 命中 `ThreatDummy` 后反馈是否足够明显
- 被打中回到出生点的节奏是否自然

---

## 当前版本定位

这是一版非常早期的动作原型。

它主要用于验证：

- 玩家基础控制是否成立
- 闪避与受击逻辑是否成立
- 基础攻击输入是否能形成最小战斗循环

后续版本才会继续扩展：

- 更完整的敌人或 Boss 行为
- 更清晰的命中反馈
- 镜头与 UI
- 更完整的战斗系统
