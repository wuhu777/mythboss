# wishqu / 我是区 游戏开发状态

## 项目目标
- 使用 Godot 4.6 制作一个 2D 动作游戏原型。
- 以小步快跑的方式逐步搭建出可运行、可玩的核心循环。
- 当前切片方向是把《元气骑士》式房间推进与《孢子》式战后器官成长做最小结合。

## 当前阶段
- 本地可玩的战斗 + 成长纵向切片阶段。
- 当前仓库已经具备常驻运行时壳、可往返双关卡、可击败训练目标、arena 清房解锁，以及单槽攻击变异选择与验证。
- 玩家攻击现在已扩展为鼠标左键轻攻、鼠标右键重击，并加入轻重切招短无敌帧。

## 当前可玩内容
- 项目可以作为 Godot 工程打开，并从 `scenes/main.tscn` 启动。
- `main.tscn` 作为常驻运行时壳，负责装载当前关卡并保留 `Player` 运行时状态。
- 玩家已具备八方向移动、定向闪避、受击回出生点、鼠标左键轻攻、鼠标右键重击。
- 轻攻与重击共用现有攻击变异系统；拾取 `blade_limb` 或 `fan_arm` 后，两种攻击都会改变判定范围与可视形状。
- 在轻攻与重击之间快速切招时，玩家会获得一个很短的无敌窗口，可用于穿过一次 dummy 的伤害判定。
- `arena_level` 中有两个可被击败的 `ThreatDummy`；全部击败后会解锁通往侧路的门。
- `side_path_level` 中提供两个攻击器官二选一：
  - `blade_limb`：攻击更长
  - `fan_arm`：攻击更宽
- 玩家选择攻击器官后，另一个拾取物会失效，并可立刻对更强的测试 dummy 验证手感差异。
- 玩家已获得的攻击变异会在关卡往返时保留。
- arena 的清房结果现在也会在同一轮运行中跨切图保留；返回 arena 时不会重新刷出已击败 dummy，也不会重新锁门。

## 当前重点
- 实际进编辑器完整走通一遍：清 arena → 进 side path → 选变异 → 测轻攻/重击 → 打测试 dummy → 返回 arena。
- 重点验证轻重切招无敌是否稳定，只在异种攻击切换时触发。
- 继续打磨两种攻击变异在轻攻/重击下的差异感与视觉辨识度。
- 保持项目始终可在编辑器中打开并运行。

## 备注 / 决策
- 默认使用 GDScript。
- 优先做小而完整的纵向切片。
- 当前攻击成长先限制为单槽、单选，不做自由拼装。
- 当前双攻击方案：轻攻（鼠标左键 / `J`），重攻（鼠标右键 / `K`），鼠标和键盘均可触发。
- 状态文件用于记录项目阶段进展；静态项目约定仍以 `CLAUDE.md` 为准。
