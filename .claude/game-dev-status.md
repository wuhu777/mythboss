# wishqu / 我是区 游戏开发状态

## 项目目标
- 使用 Godot 4.6 制作一个 2D 动作游戏原型。
- 以小步快跑的方式逐步搭建出可运行、可玩的核心循环。

## 当前阶段
- 本地可玩 demo 起步阶段。
- 当前仓库已经具备基础项目配置、主场景，以及一个最小可移动的玩家占位角色。

## 当前可玩内容
- 项目可以作为 Godot 工程打开。
- 主场景 `scenes/main.tscn` 已配置为启动场景。
- 场景中已有一个 `Player` 占位角色，并接入基础四方向移动脚本。
- 已配置 `move_left`、`move_right`、`move_up`、`move_down` 输入动作，目标支持方向键与 WASD。

## 当前重点
- 验证并打磨最小玩家移动 demo。
- 保持项目始终可在编辑器中打开并运行。

## 最近完成

- 补充并中文化项目文档与现有 skill 说明。
- 新增 `/mythboss` 主 skill 与本状态文件。
- 在主场景中接入最小玩家移动原型。
